JULIE'S PERSONAL PROFILE WEBSITE

Files:

- style.css: sky-blue theme and layout
- profile-image.png: add your own profile photo using this exact filename

How to open:
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or open the folder in Visual Studio Code and use Live Server.

Before publishing:
- Replace the sample email and social media links in the Contacts section with your real links.
- Add your own photo as profile-image.png.
- The Achievements section currently says “Secret,” as provided.

The website is responsive and uses HTML and CSS only.
